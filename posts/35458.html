2023 年脱颖而出的 7 个鲜为人知的 Linux 发行版

本文翻译自 https://news.itsfoss.com/lesser-known-distros-2023/

每年，总有一些令人兴奋的新发行版试图以不同的方式呈现，或提供某些有意义的功能，而不仅仅是“又一个发行版”。

同样，在 2023 年，也有一些发行版吸引了所有人的注意，尽管它们可能没有某些最佳 Linux 发行版那么受欢迎。

如果你一直关注我们，你可能已经知道，还有一些不可变 Linux 发行版。但遗憾的是，并非所有的发行版都能成为年度赢家。

那么，今年有哪些成功的发行版亮相呢？让我为你重点介绍以下这些：

1. Vanilla OS

Vanilla OS 是一个基于 Ubuntu 的不可变发行版。

它与其他基于 Ubuntu 的发行版不同。你可以选择在其上玩游戏、创建开发环境，或者作为日常工作的可靠工具使用。

你可以按照自己的喜好配置系统，而不会破坏使用体验。

尽管不可变性对许多人来说可能是一个新概念，但 Vanilla OS 提供了一个易于使用的用户体验，同时在底层尝试了有趣的新方法。

2. XeroLinux

XeroLinux 在 2024 年晚些时候归档，并将预配置的调整作为工具包提供，供任何人使用在任何基于 Arch 的发行版上。

XeroLinux 为新手提供了一个无需麻烦就能拥有美观的 Arch Linux 系统的好机会。

当然，如果你从未使用过 Linux 发行版，这可能并不是一个适合你的起点。但如果你知道自己在使用 Arch Linux 时需要一些帮助，XeroLinux 可以优雅地实现这一点。

它不仅提供了一个良好的开箱即用外观，还让你可以微调和定制使用体验。

3. Ubuntu Unity

最初是一个非官方的 Unity 驱动的 Ubuntu Remix，旨在复兴 Unity7 桌面环境，Ubuntu Unity 现已成为官方 Ubuntu 风味之一。

在 2023 年，它脱颖而出，让一些 Linux 用户重新体验了 Unity 桌面环境（这是 Ubuntu 在 17.10 之前的默认桌面）。

4. Crystal Linux

这是一个基于 Arch 的发行版，内置了 GNOME 桌面。 Crystal Linux 旨在利用最新技术，同时提供熟悉的用户界面。

如果你想在 Arch 发行版上体验定制的 GNOME 界面，Crystal Linux 是你的选择。本文撰写时，它仍处于测试阶段。

不过，它包含了帮助你开始日常使用的所有必要功能（尽管我建议不要在生产环境中使用）。

5. Bazzite

Bazzite 是一个基于 Fedora 的 Linux 发行版，让你在桌面或 Steam Deck 上轻松游戏。

它包括专有的显卡驱动程序和预装的应用程序（如 Mission Center 和 Discover Overlay），为你带来有趣的入门体验。

你可以根据用途（例如流媒体、游戏等）选择安装的应用程序。

与其他 Linux 发行版不同，它支持各种游戏硬件，例如 Xbox 手柄、雷蛇设备等。

6. Fedora Asahi Remix

我们都在关注 Asahi Linux 项目，这个项目让 Apple Silicon 上运行 Linux 成为可能。

他们已经成功了，以 Fedora Asahi Remix 作为旗舰发行版。如果你想在最新的 Apple Silicon 设备上使用 Linux，可以安装 Fedora Asahi Remix。

它内置了 KDE Plasma 桌面，还可以选择使用 GNOME 45，以及其他定制选项来帮助你入门。

此外，你将获得仅支持 Wayland 的体验，并通过 XWayland 支持 X11 应用程序。

7. CachyOS

没错！2023 年确实有许多基于 Arch 的发行版成功吸引了人们的关注。

而 CachyOS 又是其中之一。

与其他发行版不同，它纯粹专注于为你提供快速、优化的 Linux 体验，同时加强了安全性。CachyOS 利用了 先进的 BORE 调度器 和使用优化指令及 LTO 编译的内核，提供最佳性能。

这可能并不适合初学者，但你可以选择各种桌面环境，包括一些窗口管理器。

总结

通常是那些不被看好的发行版，为 Linux 用户提供了令人兴奋和实用的体验。你永远不知道会遇到什么，对吧？

当然，对大多数人来说，选择受欢迎的 Linux 发行版更安全。但如果你想尝试一些不同的东西，这些鲜为人知的发行版可能会让你耳目一新。
