Tuxedo 发布首款基于骁龙 X Elite 的 ARM 笔记本电脑

本文翻译自 https://debugpointnews.com/tuxedo-drako-laptop/

这是 Linux 用户的好消息！专注于为 Linux 打造电脑的 Tuxedo Computers 宣布，他们正在开发一款使用高通 Snapdragon X Elite 芯片的 ARM 架构 Linux 笔记本。

这一进展令人兴奋，因为苹果和 Windows 设备已经开始使用 ARM 架构芯片，而 Linux 笔记本在从传统的 x86 架构过渡上稍显滞后。

Snapdragon X Elite 芯片是高通的高端笔记本芯片，Tuxedo 的笔记本将成为首款采用该芯片的 Linux 笔记本。这是一个非常有前景的选择，因为高通声称 Snapdragon X Elite 的性能和效率优于苹果的 M2 芯片。

Tuxedo 在 Computex 展会上展示了代号为“Drako”的笔记本原型。尽管还有一些问题需要解决，例如驱动程序，Tuxedo 预计将在 2024 年年底前推出最终产品。

原型机的简要规格如下，最终产品可能会有所不同：

  • Snapdragon X Elite X1E80100
  • Oryon 核心，主频 3.8 GHz
  • 双核加速频率 4.6 GHz
  • Adreno GPU – 1.25 GHz
  • 8+4 PCIe 4.0 通道，2+2 PCIe 3.0 通道
  • 集成 NPU，45 Teraflops 的 AI 工作负载性能

然而，高通表示，这款 SoC 不适合高端笔记本或游戏笔记本，而更适合像 Pulse 或 InfinityBook Pro 这样的商用笔记本。

使用 ARM 芯片的好处之一是效率更高，但在 ARM 笔记本上运行 Linux 可能会有一些挑战。然而，高通与 Linaro 合作，使 Snapdragon X Elite SoC 能够支持 Linux，这可能会使该过程变得更加顺利。

针对该芯片的驱动程序正在进行上游合并，预计部分驱动程序将在 Linux 6.9 内核中推出，高通预计到 Linux 6.11 内核时，所有驱动程序都将支持。

不过，最终的成功与否还有待观察。苹果 M 系列芯片的主要卖点是巨大的电池续航，而这正是大家最关心的点。AI 工作负载、RAM 和计算能力都很重要，但高计算性能下的电池节省才是关键。此外，这款设备的定价将是其成败的关键因素。

请继续关注 Tuxedo 的更新，预计这款笔记本将于 2024 年圣诞节期间发布。
