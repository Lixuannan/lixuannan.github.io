2023 年的 8 个 Linux 决定性瞬间

2023 年的 8 个 Linux 决定性瞬间

本文翻译自 https://news.itsfoss.com/best-open-source-linux-stories-2023/，选作课文时有删改。

每年，Linux 和开源世界都会带来一些惊喜和震撼。

可能会有某个 Linux 发行版改变了它的基础，某个独立项目被大型科技公司接管，或者发生其他各种事情。在 2023 年，我们尽最大努力为你带来这一系列过山车般的体验。

现在，2023 年已经结束（译者注：很久很久了），是时候回顾一下这一年发生的重大新闻了。

1. Ubuntu 推出了 "Flutter" 商店 ⭐

Ubuntu 的软件中心总是因其变化和改进而备受关注。

今年，Ubuntu 通过在 Ubuntu 23.10 中引入基于 Flutter 的新 "Ubuntu 商店" 提升了其表现，提供了现代且简洁的用户体验。

这将最终取代 Ubuntu 多年来的老旧软件中心，这对我来说是件好事。

2. 印度国防部门转向 Linux

印度国防部决定用名为 "Maya" 的自研 Linux 发行版取代 Windows。

当然，这并不是政府机构第一次选择使用 Linux 来提高安全性和隐私性。

然而，在像印度这样的大国，政府一部分机构选择使用 Linux 的简单决定可能会对其他系统产生巨大影响。这对 Linux 整体来说是件好事。

3. Red Hat 锁定源代码 🔒

作为全球最大的开源公司，Red Hat 决定将 Red Hat Enterprise Linux 的源代码放在付费墙后面。

虽然他们仍允许个人开发者通过免费订阅访问源代码，但这不再像以前那样向所有人公开。

这一变化给所有基于 RHEL 的发行版和分支带来了冲击：

从 SUSE、Oracle 等竞争对手联合开发 RHEL 分支，到 Rocky Linux 和 AlmaLinux 等项目发生的各种变化。

对我来说，这是 2023 年最大的新闻，它的影响将持续到 2024 年。

4. Linux 内核 LTS 支持周期的变化

为了减轻维护人员的负担，LTS 内核的支持周期从 六年 缩短到了两年。

评估结果显示，使用旧版 Linux 内核的人并不多，而随着多个 LTS 版本内核的长期维护，维护人员的工作变得艰难而枯燥。

作为用户，除非你依赖于不再受新内核支持的特定硬件，否则你无需担心这一变化（译者注：我有一个哥们儿就是因为这个问题一直在用 Slackware 远古版）。

5. Ubuntu 取消对所有版本的 Flatpak 支持 🔨

毫不意外，Canonical 的 Ubuntu 更偏向 Snap 包而非其他软件包。

然而，Ubuntu 的衍生版本（如 Ubuntu MATE）曾经有自由提供 Flatpak 支持。

不幸的是，Ubuntu 取消了对这些版本的默认 Flatpak 支持，理由是为了提供一致的用户体验。

当然，你可以手动添加 Flatpak 支持，但它不再是开箱即用的便利了。

6. 滚动发布的 Ubuntu 发行版出现 🎲

在所有其他有趣的发行版中，Rhino Linux 稳定版发布。它旨在提供基于 Ubuntu 的滚动发布体验。

7. Vim 的创建者去世 🥺

今年，我们失去了 Linux 社区的一位杰出人物——Bram Moolenaar，他是 Vim 文本编辑器的传奇人物。

让我们一起帮助乌干达的可怜儿童！

8. Linux 在 macOS 游戏统计数据中超越

今年，Linux 用户在 Steam 的统计报告中，使用率超过了 macOS。

遥遥领先～
