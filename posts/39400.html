Kindle 电子书转 PDF 并移除 DRM 教程

本文翻译自 https://itsfoss.com/calibre-remove-drm-kindle/

你从 Amazon Kindle 购买了电子书，现在想在个人电脑或其他没有 Kindle 应用的设备上阅读？但由于 Kindle 电子书受到 DRM（数字版权管理）保护，它们只能在 Amazon 生态系统内阅读，例如使用 Kindle 应用或 Kindle Cloud Reader，而无法直接导出为 PDF。

不过，你可以借助开源软件 Calibre 及其插件 DeDRM，将 Kindle 电子书转换为 PDF。以下是详细步骤。

⚠ 注意：

本方法不适用于 Kindle Fire 平板。

步骤 1：安装最新版本的 Calibre（7.x）

在 Linux 上，你可以使用以下命令安装最新的 Calibre 7.x 版本（推荐 7.6.0）：

步骤 2：安装 DeDRM 插件

⚠ DeDRM_tools 插件已停止维护，但目前仍可在 Calibre 的新旧版本中使用。如有问题，可查找 GitHub 上的最新分支。

  1. 访问 DeDRM_tools 的 GitHub 下载页面。
  2. 下载最新版本的 ZIP 文件。

步骤 3：加载 DeDRM 插件

  1. 解压下载的 ZIP 文件（其中包含两个插件，我们需要选择 DeDRM_plugin.zip）。
  2. 打开 Calibre，按 Ctrl + P 进入 首选项（Preferences） 。
  3. 点击 插件（Plugins） → 从文件加载插件（Load plugin from file）。
  4. 选择 DeDRM_plugin.zip 文件并打开。
  5. 可能会弹出安全警告，点击 “是” 确认安装。
  6. 看到插件成功添加后，点击 “应用（Apply）”，然后重启 Calibre 使插件生效。

步骤 4：添加 Kindle 设备的序列号到 DeDRM 插件

要移除 DRM，需要获取 Kindle 设备的 序列号（Serial Number），然后输入到 DeDRM 插件中。

获取 Kindle 序列号

  1. 访问 Amazon 账户 并点击 账户与列表（Account & Lists）。
  2. 找到 设备（Devices） 选项。
  3. 选择你的 Kindle 设备，点击设备名称查看详细信息。
  4. 复制 Kindle 序列号。

添加到 DeDRM 插件

  1. 在 Calibre 中，依次打开 首选项（Preferences） → 插件（Plugins） → 文件类型（File Type）。
  2. 双击 DeDRM 插件，点击 eInk Kindle ebooks。
  3. 点击 ➕ 按钮，输入 Kindle 序列号并保存。

步骤 5：下载 Kindle 电子书

  1. 进入 Amazon 账户 → 内容库（Content Library）。
  2. 找到已购买的 Kindle 电子书，点击 更多操作（More actions） → 下载并通过 USB 传输（Download & transfer via USB）。
  3. 选择与你的 Kindle 设备匹配的选项后，点击 下载。

步骤 6：将 Kindle 电子书转换为 PDF

  1. 在 Calibre 中点击 添加书籍（Add books），选择刚下载的电子书文件。
  2. 选中书籍，点击 转换书籍（Convert books）。
  3. 在 输出格式（Output format） 中选择 PDF，然后点击 确定（OK）。
  4. 等待转换完成后，在书籍列表中右键点击 PDF 版本，选择 保存到磁盘（Save to disk）。

常见问题
