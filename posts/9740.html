关于 Linux & Windows 双系统的辟谣

关于 Linux & Windows 双系统的辟谣

本文翻译自 https://itsfoss.com/dual-boot-myths/

安装双系统算是一种超能力，你可以在一台计算机上安装两个操作系统，并在启动时切换它们。

如果你是第一次听说双系统，建议你阅读我们关于双系统的文章，了解更多关于这种强大功能的信息。

而且，最流行的双系统组合是 Linux 和 Windows。因此，你可以不做妥协地享受两个系统的优点。

然而，围绕这种双系统组合存在一些误区。在这里，我将根据自己超过十年的双系统经验，为你揭示这些误区的真相。

1. 双系统会让你的系统变慢

如果你已经使用双系统了一段时间，你一定曾经遇到过一些人坚信双系统会影响系统速度的想法。

幸运的是，这是不正确的，因为在任何时候你只会使用一个操作系统。

当你看到 grub 屏幕或双系统屏幕，显示两个选项时，你只是选择加载哪个操作系统来使用你的电脑。它可以是 Windows 或 Linux 发行版。

所以，当你选择其中一个时，另一个操作系统将不会启动，静静地躺在硬盘中，直到你重启并选择它。

这从未让我的系统变慢，也不会让你的系统变慢。

2. 双系统仅仅是关于 Windows 和 Linux

我使用的是 Windows 和 Linux 的双系统设置，这是大多数用户的常见选择。

但这并不意味着这是唯一的选择。

你可以选择安装两个 Linux 发行版进行双系统，也可以选择两个 Linux 发行版和 Windows 的组合。就像这样：

3. 你无法在启用安全启动的情况下进行双系统

当涉及到启用安全启动的双系统时，你只能选择某些支持它的 Linux 发行版（并提供相关文档）。但这并不意味着不可能。

例如，Ubuntu 支持与启用 UEFI 安全启动 进行双系统。

你可以按照我们关于 安装 Ubuntu 和 Windows 双系统 的教程进行操作。

4. 双系统系统需要两块硬盘

虽然我承认我为了方便而使用了两块硬盘进行双系统，但这并不是每个人的做法。

很多用户只有一块硬盘，并将第二个操作系统安装到一个单独的分区中进行双系统。Linux 发行版通过在安装过程中提供“在 Windows 启动管理器旁安装 Ubuntu”选项，使得这变得更加容易：

你只需要在选择启动加载器的路径和安装操作系统的分区时更加小心。但这完全是可能的。

5. 你必须在 Windows 之后安装 Linux

大多数 Windows 用户认为安装 Linux 作为辅助操作系统是显而易见的。我发现这很安静舒服，即使你依赖某些 Windows 专用应用程序进行工作。

所以，这成了流行的做法。但实际上也可以反过来。如果你已经安装了 Linux，你可以稍后安装 Windows 而不会遇到任何问题。就像我们在这里做的：

如何在 Ubuntu Linux 后安装 Windows 双系统

或者，如果你什么都没安装，你也可以选择先安装 Linux，再安装 Windows，完全没有区别。

6. 你不能在不格式化整个系统的情况下返回 Windows

无论当前安装的是 Linux 还是 Windows，你都可以随时返回你的最爱操作系统。

假设你想将 Windows 作为日常操作系统，而不是使用 Linux 发行版。

在这种情况下，你需要做的就是将 Windows 作为第二个操作系统添加到双系统中，然后删除格式化存放 Linux 的分区，仅此而已：
