为什么这个轻量级 Linux 发行版不会赢得任何用户数比赛，但对于高级用户来说却是完美的

为什么这个轻量级 Linux 发行版不会赢得任何用户数比赛，但对于高级用户来说却是完美的

本文翻译自 https://www.zdnet.com/article/why-this-lightweight-linux-distro-wont-win-any-popularity-contests-but-is-perfect-for-power-users/

AntiX 对许多用户来说都颇为熟悉。

一款 Linux 发行版若能摒弃大多数发行版奉为圭臬的传统，还能提供功能强大、运行快速且易于使用的桌面操作系统，是否可能？这正是 AntiX 所做的。

虽然这款基于 Ubuntu 的发行版更适合熟悉 Linux 的用户，AntiX 也并非完全不适合新手。为何这款发行版更适合有经验的用户？是因为它没有使用 systemd 吗？并不是。大多数新用户很少（甚至从未）需要关心启动服务的问题。是因为桌面包含了 Konky（一个显示各种信息的小工具）吗？也不是。Konky 并不会影响桌面的实际使用体验。

推荐 AntiX 给有经验用户的主要原因在于它采用了 zzzFM-IceWM 窗口管理器。尽管开发者尽力让 IceWM 看起来与大多数桌面类似，但当你尝试修改设置时，很快就会意识到 AntiX 并不是那种“简单易用”的操作系统。

在 zzzFM-IceWM 中，有一个专门的“设置”菜单，包含三个子菜单：

  • Focus: 配置窗口焦点，包括传统、严格、随意或安静模式。
  • Preferences: 配置 QuickSwitch、任务栏、显示设置、快捷键等。
  • Themes: 定制桌面主题。

AntiX 菜单中选项众多。

主题丰富

说到主题，AntiX 提供了相当多的主题，从简单的配色方案到大规模主题、玻璃风格主题等，应有尽有。你几乎可以找到一个合自己心意的主题。不过，这些主题都无法让 AntiX 看起来像现代桌面。对于大多数新用户来说，定制桌面外观的概念可能也并不熟悉。

应用众多

AntiX 提供了一个 GUI 软件包安装器。由于该系统基于 Ubuntu，你可以选择数千款应用。此外，AntiX 还支持通过 GUI 配置丰富的软件源，这在大多数发行版中并不常见。

预装的软件也相当丰富，包括 Firefox、LibreOffice、Firejail，以及多款多媒体播放器（如 Streamtuner2 网络电台应用）。尽管某些应用（例如 Firejail，用于沙盒应用）可能对新用户不太友好，但选择范围确实很广。

尽管界面不够现代化，AntiX 应用商店的功能依然实用。

性能卓越

由于 AntiX 使用了轻量级窗口管理器，其性能非常出色。该系统运行飞快，所需的硬件配置远低于 Windows 11 的要求。这对拥有旧电脑的用户来说是个好消息。我在一个只有 3GB RAM 和 2 核 CPU 的虚拟机中测试 AntiX，其速度和响应都非常令人满意。

应用程序不仅几乎是瞬间启动的，而且安装速度也非常快。我测试安装 Plasma 桌面环境，用时不到一分钟。退出后选择 Plasma 作为桌面环境重新登录时，我发现 AntiX 仍然运行流畅。虽然 Plasma 的速度无法与 zzzFM-IceWM 相媲美，但差距并不大。

AntiX 适合谁？

AntiX 的核心特性之一是缺少 systemd 启动服务。由于种种原因，Linux 社区的一部分用户不愿使用 systemd，倾向于老式方法。但反对 systemd 的用户并不是唯一适合 AntiX 的群体。如果你希望让老旧硬件焕发生机，体验现代桌面兴起之前的 Linux，或者学习一些在 Ubuntu、Linux Mint 或 elementary OS 上学不到的 Linux 知识，AntiX 是一个不错的选择。

然而，如果你只是想要一款符合现代审美的桌面操作系统，或者对是否使用 systemd 并不在意，那么 AntiX 可能并不适合你。你可以从 官方下载页面 下载 AntiX 的最新版本（23.2）。
