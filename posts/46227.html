Thunderbird 中轻松管理邮件的几个小技巧

本文翻译自 https://itsfoss.com/thunderbird-threading/

从版本 102 开始，Thunderbird 提供了 消息话题 作为解决此问题的功能。

在消息话题中，单独的对话将以树状结构排列。因此，对于特定的发件人，你可以在一个大的对话话题下查看消息和回复。

以下是消息话题视图的一些功能：

  • 组织对话。
  • 轻松访问整个对话的所有消息。
  • 可以一次性轻松删除整个对话。
  • 不会错过特定对话中的任何消息。
  • 忽略话题，这将隐藏该话题并禁用新回复的通知。
  • 忽略子话题，从选定消息开始忽略回复。

在本教程中，我将分享一些关于 Thunderbird 消息话题的技巧。

启用和禁用文件夹的消息话题

正如前面所说，从版本 102 开始， Thunderbird 默认启用消息话题。如果对你的 Thunderbird 不是这样，让我们看看如何启用它。

点击 Thunderbird 顶部栏上的 消息列表显示选项 按钮。

转到 排序方式 → 话题。

效果如下：

如上图所示，我已在 收件箱 文件夹中启用话题视图。现在，如果你想在另一个文件夹中管理话题视图呢？

假设你有一个过滤器，将来自特定发件人的所有消息移动到一个名为 个人消息 的专用文件夹中。选择侧边栏中的该文件夹，然后重复上一步。

也就是说，消息列表按钮 → 排序方式 → 话题。

这将为该文件夹启用话题视图。

禁用话题

要禁用当前文件夹的话题视图，请选择你选择的文件夹，然后执行 消息列表选项按钮 → 排序方式 → 不话题。

为多个文件夹启用和禁用消息话题

如你所见，你可以在 Thunderbird 中更改每个文件夹的话题视图。现在，有时能够一次性将话题视图设置应用于多个文件夹将会很有用。

在 Thunderbird 中启用表格视图

为了启用表格视图，你首先需要处于表格视图。点击 消息列表显示选项 按钮并选择表格视图。

现在，你将获得带有一些默认列的表格视图。

在文件夹中启用和禁用消息话题

你首先需要将话题设置应用于当前文件夹。要切换话题，你可以使用常规的 消息列表按钮 → 排序方式 → 话题。

但在此视图中，有一个特别之处。你可以通过单击最左侧列标题的 切换消息话题 按钮轻松切换消息视图。

将话题应用于文件夹

在表格视图中，单击列标题右侧的 选择要显示的列 按钮。选择 将当前视图应用于 选项并悬停在 文件夹 上。

在文件夹选项上，选择你的邮箱帐户，然后选择要应用视图的文件夹。

这将询问确认。单击确定以应用。

该视图将应用于你选择的文件夹。

将应用于文件夹及子文件夹

你是否有一堆文件夹和子文件夹并希望更改为话题视图？在 Thunderbird 中也是可以的。

如前所述，在文件夹上设置话题视图。现在，单击 选择要显示的列 → 将当前视图应用于。

现在，选择 文件夹及其子文件夹 选项。转到你的帐户，然后选择要应用视图的父文件夹。

这会询问你是否允许将视图应用于文件夹及其子文件夹或子项。

通过单击确定按钮给予许可。

这样。你已经成功应用了它。

通过这种方式，你也可以将视图设置应用于整个邮箱帐户。

修改默认话题视图

在 Thunderbird 中，你可以强制新创建的文件夹遵循 话题视图 或 非话题视图。这样，你可以保持现有文件夹的视图，并更改新文件夹的视图。

要做到这一点，请单击右上角的汉堡菜单，然后选择 设置。

转到 常规 选项卡，向下滚动到底部，然后选择 配置编辑器 选项。

在搜索栏中，搜索 mailnews.default_view_flags。然后单击编辑按钮，如下所示。

这里，值 0 表示 非话题视图，值 1 表示 话题视图。

正如你在上面的截图中看到的，这个默认值是 1。我们将其更改为 0，以便新文件夹将遵循非话题视图。单击勾选按钮以应用更改。

要将其重置为默认值 (1)，只需按下标志旁边的重置按钮。

使用话题的方式

你已经看到几种可以切换 Thunderbird 中 话题视图 的方法。现在，让我们看看在 Thunderbird 中使用 话题 的一些常见方式。

忽略话题

你可以忽略特定的 话题，这样它将从视图中隐藏。对于该话题的进一步回复通知将被禁用。

右键单击 消息话题 并选择 话题 → 忽略话题。

就这样。该话题将从你的视图中消失。

要查看被忽略的话题，首先按下键盘上的 ALT 键以显示主菜单。现在，从主菜单中选择 查看 → 话题 → 被忽略的话题。

现在，你将能够在所选文件夹中看到被忽略的消息，左侧有一个小红色减号。当悬停时，它会显示“该话题消息被忽略”。

右键单击被忽略的消息，然后取消选中 忽略话题 将移除该话题的忽略。

忽略子话题

忽略一个 子话题 意味着你可以从选定消息开始忽略进一步的回复通知。这特别好，尤其是当对话失去控制时，你不想以任何方式继续，于是你可以忽略某个话题。

展开 话题消息，然后选择你要忽略的消息。

你可以使用前一节中提到的方法查看被忽略的话题。

总结

你也可以通过键盘快捷键实现许多上述讨论的技巧。以下是相应的表格。

功能 快捷键
移动到下一个 UI 元素 Tab
移动到上一个 UI 元素 SHIFT + Tab
移动到下一个主 UI 区域 F6
移动到上一个主 UI 区域 SHIFT + F6
展开和折叠选定的 话题 右箭头和左箭头键
展开所有话题 *
折叠所有话题 \
在对话视图中打开选定消息和相关消息 (新标签) CTRL + SHIFT + O
将话题标记为已读 R
忽略或取消忽略话题 K
忽略或取消忽略子话题 SHIFT + K
观看/取消观看一个话题 W
转到下一个未读话题 (并将当前话题标记为已读) T
