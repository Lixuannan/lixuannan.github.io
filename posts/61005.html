15 个提升 VSCode 编码体验的小技巧

本文翻译自 https://itsfoss.com/vs-code-tips/

VS Code 是当今开发人员的首选，市场占有率十分的高。

如果你是 VS Code 的用户，我想分享一些技巧和调整，帮助你提高工作效率并改善编程体验。

想要更高效吗？熟悉并记住这些适用于 Linux、Windows 和 macOS 的 VS Code 键盘快捷键。

感兴趣了吗？让我们一起来看看吧。

1. 集成终端和多配置文件

首先，你可以使用快捷键 CTRL+‵ 打开 VS Code 的集成终端。

功能 快捷键
启用集成终端 CTRL+‵
在外部终端中打开位置 CTRL + SHIFT + C

现在，你可以从下拉菜单中选择所需的 shell。

你还可以使用不同的配置文件分割终端。在集成终端顶部的加号按钮旁边的下拉菜单中点击 分割终端，然后选择所需的配置文件。

2. 分割编辑器

VS Code 支持分割视图和编辑器组。

通常，你可以使用 CTRL+\ 来水平分割视图，两个编辑器将并排显示。

功能 快捷键
分割编辑器 CTRL+\
关闭活动分割 CTRL+W
在上方创建分割 CTRL+K CTRL+\
在分割视图间切换 CTRL+1/2/3...

你可以为每个分割视图打开不同的文件，从而形成编辑器组。

此外，你还可以创建多个其他布局，例如网格布局。点击 视图 → 编辑器布局 → 选择布局 来选择。

3. 快速创建文件

如果代码中指定了一个文件，你可以按住 CTRL 键并点击它来打开。

如果文件不存在，你将收到提示，创建该文件并在新标签中打开。

4. 快速滚动

浏览大型代码文件时，按住 ALT 键并滚动鼠标滚轮可以实现 5 倍速度的快速滚动。

5. 同步滚动

比较两个文件时，保持滚动同步非常有帮助。按 CTRL + SHIFT + P，搜索“Toggle Locked Scrolling Across Editors”，并启用它。

6. 粘性滚动

当你处理有多个章节的大型文件时，启用粘性滚动可以让你当前编辑的章节固定在编辑器顶部。

按 CTRL + SHIFT + P，搜索并启用“Toggle Editor Sticky Scroll”来开启粘性滚动。

7. 多光标编辑

按住 ALT 键并点击多个位置，可以同时在多个位置添加光标。

你还可以使用 CTRL + SHIFT + L 将额外光标添加到当前选择的所有出现处。

8. Markdown 预览

你可以使用 CTRL + SHIFT + V 在新标签中预览 Markdown 文件，或使用 CTRL+K V 在分割视图中进行实时预览。

9. Zen 模式

如果觉得界面过于杂乱，可以按 CTRL + K Z 启用 Zen 模式，进入专注的代码编辑界面。

10. 上下移动代码行

使用 ALT + 上箭头 或 ALT + 下箭头 可以上下移动代码行。

11. 重命名函数/变量

选择要重命名的变量，按 F2，输入新名称，然后按 Enter，它将在所有出现处被重命名。

12. 格式化整个文档

使用 CTRL + SHIFT + I 可以格式化整个文档。

13. 注释/取消注释多行

在 Linux 中，可以使用 CTRL + SHIFT + A 注释或取消注释多行。

14. 简单浏览器

VS Code 提供了一个简单的浏览器扩展，主要用于显示网页内容。

你可以按 CTRL + SHIFT + P 并搜索 Simple Browser 来访问（译者注：这个插件已经被弃用了）。

15. 双击保持文件活动

浏览器中的文件默认行为是在未修改时自动关闭。如果你想保持文件处于活动状态，可以在打开时双击它。
