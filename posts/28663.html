Ubuntu 和 其他 Linux 发行版上的最佳浏览器

本文翻译自 https://itsfoss.com/best-browsers-ubuntu-linux/

没有所谓的“完美”网页浏览器，关键在于你的个人偏好和用途。

那么，Linux 上有哪些优秀的网页浏览器可供选择呢？

在本文中，我将介绍适用于 Ubuntu 及其他 Linux 发行版的最佳浏览器。

📋我们已经在 Ubuntu 上对这些浏览器进行了测试。但你应该可以在任何 Linux 发行版上安装它们。

每款浏览器都有其独特之处，而在 Linux 平台上，还有一些专属的有趣选择。

⚠ 非开源软件警告！ ⚠ 文中提到的一些应用程序并非完全开源，但它们可以在 Linux 上运行，因此本文将它们列出。

1. Vivaldi

优点：

  • 侧边栏快捷访问 Web 应用
  • 内置日历和邮件功能
  • 独特的标签管理
  • 番茄钟（计时器）功能
  • 提供移动端应用

缺点：

  • 启用多个功能时资源占用较高
  • 不是完全开源

Vivaldi 是一款令人印象深刻的浏览器，越来越受到 Linux 用户的关注。

虽然它并非 100% 开源，但你可以在线获取大部分源代码（除了 UI 部分）。

新版本在不断优化 Linux 体验，例如：

  • 设置计时器，提高工作效率
  • 内置网页翻译
  • 内置日历和 Web 应用快捷方式
  • 出色的多任务处理能力

尽管 Vivaldi 速度快，但并非最轻量或最快的浏览器。如果想充分利用其所有功能，你需要足够的内存（RAM）。

总体而言，它是一款功能丰富的浏览器。如果你需要强大的多任务功能，Vivaldi 可能是你的最佳选择。

🔗 Vivaldi 官网

Vivaldi 提供了适用于 Ubuntu 和 Debian 的 .deb 包，以及适用于 Fedora、Red Hat 和 SUSE Linux 的 .rpm 包。 👉 下载 Vivaldi

2. Mozilla Firefox

优点：

  • 强大的隐私保护
  • 非基于 Chrome 内核
  • 开源
  • 提供 Firefox 账户服务

缺点：

  • 重大更新可能会带来用户体验变化

Firefox 是大多数 Linux 发行版的默认浏览器，自然是首选之一。

除了完全开源外，Firefox 还提供了一些最强大的隐私保护功能。如果进行适当的设置，它甚至可以像 Tor 浏览器（基于 Firefox）一样安全。

此外，Firefox 还集成了：

  • Pocket（网页稍后阅读）
  • VPN（需订阅）
  • 电子邮件别名（防止垃圾邮件）
  • 数据泄露监测

🔗 Firefox 官网

Firefox 通常预装在 Linux 发行版中。如果没有，你可以在软件中心搜索或按官网指示安装

3. Chromium

优点：

  • 开源的 Chrome 替代品
  • 拥有与 Chrome 类似的功能

缺点：

  • 缺少 Chrome 提供的一些专有功能

Chromium 是 Google Chrome 以及许多其他基于 Chrome 的浏览器的开源基础版本。

如果你不想使用 Google Chrome，但仍想要相同的浏览体验，Chromium 是不错的选择。

🔗 Chromium 官网

4. Google chrome

优点：

  • 与 Google 服务无缝集成

缺点：

  • 非开源

Google Chrome 是一款强大的浏览器，尤其适合那些依赖 Google 生态的用户。

如果你在 Android 设备上使用 Chrome，并希望在桌面端同步数据，那么它是一个理想选择。

🔗 Google Chrome 官网

Google Chrome 提供 .deb 和 .rpm 安装包，适用于 Ubuntu、Fedora、openSUSE 等系统。

5. Brave 浏览器

优点：

  • 隐私保护
  • 高性能

缺点：

  • 无云端同步功能

Brave 是一款基于 Chromium 的开源浏览器，以隐私保护和极速体验著称。

独特功能：

  • 内置广告拦截
  • 加密保护
  • Brave Rewards：用户可以屏蔽广告，同时通过 Brave 代币支持喜欢的网站。

🔗 Brave 官网

Brave 无法直接从软件中心安装，需要使用命令行安装。

6. Opera

优点：

  • 内置免费 VPN
  • 额外功能丰富

缺点：

  • 非开源

Opera 适合需要额外功能（如 VPN 和广告拦截）的 Linux 用户。

🔗 Opera 官网

Opera 提供 .deb 包，需从官方网站下载。

7. Microsoft Edge

优点：

  • 适合 Windows & Linux 双系统用户

缺点：

  • 非开源

Microsoft Edge 在流行度上已经超越了 Mozilla Firefox。这不仅是因为它是 Windows 的默认浏览器，还因为它基于 Chrome，并提供了良好的网页浏览体验。

如果你还不知道，Microsoft Edge 也可以在 Linux 上使用。

总体而言，你应该能够在 Edge 上找到大多数必备的功能。

如果你同时使用 Windows 和 Linux 作为桌面操作系统，那么 Microsoft Edge 可能会成为一个实用的浏览器选择。

🔗 Microsoft Edge 官网提供 .deb 和 .rpm 安装包。

8. GNOME Web（Epiphany）

优点

  • 简约
  • 开源

缺点

  • 缺少许多功能
  • 不支持跨平台同步

Epiphany 是 GNOME 桌面的默认浏览器，但像 GNOME OS 一样，很多人并不了解它。elementary OS 也将其作为默认浏览器。

它是一款极简浏览器，提供干净优雅的用户体验。然而，它不支持书签和浏览历史同步，如果你需要备份或在不同浏览器之间转移数据，就需要手动导出。

🔗GNOME Web

某些 Linux 发行版可能已预装 GNOME Web。如果没有，你可以安装其 Flatpak 版本，以获得最新版本。

9. Falkon

优点

  • 使用轻量级的 QtWebEngine 渲染引擎

缺点

  • 缺少许多功能

Falkon 是一款基于 QtWebEngine 的浏览器，注重隐私保护。它适用于基本的网页浏览，但可能无法满足日常使用需求。

Falkon 可用于 Windows 和 Linux。

🔗Falkon

你可以在大多数 Linux 发行版的默认软件源中找到 Falkon。如果找不到，可以使用其 Flatpak 安装文件 或 Snap 版本 进行安装。

10. Nyxt

优点

  • 高度可定制
  • 主要以键盘操作为主

缺点

  • 适合特定用户群体
  • 不支持跨平台同步

Nyxt 是一个专为高级键盘用户设计的浏览器，你可以通过快捷键进行网页浏览和导航。

🔗Nyxt

Nyxt 可在 Arch Linux 的额外软件库中找到。对于其他发行版，你可以安装其 Flatpak 版本。

总结

在 Linux 上，你可以选择的浏览器种类繁多。我特意没有提及基于命令行的网页浏览器，如 Lynx。
